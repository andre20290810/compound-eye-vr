# v64 運動ダイナミクスタイムライン

## 目的
複数部位の運動状態とピーク順を、3D再生を見ながら共通時間軸上で比較する。関節名の3Dラベルを増やさず、時間位置・球の大きさ・色で身体機能の変化を読む。

## 表示と操作
- 単画面ではタイムラインをビューアー横に置く。狭い画面ではタイムラインをビューアー上に積む。
- 複眼時はタイムラインをビューアー上、従来のビューアー操作ボタンを下に置く。
- X/Yの選択操作はタイムライン付近。再生中の位置カーソルと各部位の球は同じ描画時刻に追従する。
- 数値波形、解析条件、CSV/JSON出力はビューアー下の折りたたみパネルに残す。
- 3Dの関節マーカーは任意で、文字ラベルは付けない。

## 時間軸と符号化
- 既定は元時刻（秒）。局面合わせではX/Yそれぞれの動作時間を0〜100%に正規化し、Yの解析区間もYの動作時間に換算してピーク・増減状態を求める。
- 各行は選択部位。増速・減速・低活動・ピークの帯とピーク菱形を表示する。再生カーソル上の球はXが塗り、Yが輪郭。球色は運動状態色、球径はその部位・指標内の速度変化量を基準に3〜10で正規化する。
- 同じ部位・同じ指標でX/Y速度差が設定割合（初期値15%）を超える区間に差分帯を表示する。異なる単位・部位間の速度の大小は比較しない。
- 3D重ね合わせは互換性検査を通過したXBot/YBotに限定。差分色エディターの色を、姿勢差のある関節の影響領域に適用する。色はブラウザー内に保存する。

## 解釈上の範囲
表示は位置・姿勢から算出した運動学的特徴と時刻差を示す。力、トルク、エネルギー伝達、因果、技能の優劣を意味しない。3D差分の初期検出基準は局所回転5度以上または並進0.025モデル単位以上。
