# v60 — 肩装甲の削除・バイザー形状調整

基準版は公開v59の `ba7b697`。`backup-v59-before-v60-20261112` に変更前を保存。利用者が編集した `public-appearance.json` は内容・revisionとも変更せず、そのまま引き継ぐ。

## 反映内容

AEGIS NAVY / SOLDIERの両方について、v59で追加した肩装甲と縁取りを完全に削除した。追加装甲メッシュを生成・GPUアップロードせず、肩だけの旧描画行列も実行しない。元モデルに含まれる肩・腕・ケーブルはそのまま。旧版のソース／証跡は履歴として保存し、現行HTMLに肩装甲モジュールを組み込まない。

画面上部に **「バイザー調整」** を追加した。既存の配色ウィンドウ内の形状欄を直接開く。配色の部位選択で「バイザーの2本線・▲」を選んでも同じ欄を開ける。各設定はスライダーと数値入力の両方に対応し、その場で描画へ反映する。

| 操作 | 範囲 | 新しい初期値 |
|---|---|---|
| ▲の大きさ | v59基準の25〜300% | 150% |
| 白線の太さ | v59基準の20〜150% | 60% |
| 左の線の傾き | −60〜+60° | 0° |
| 右の線の傾き | −60〜+60° | 0° |
| 白線の長さ | 50〜150% | 100% |
| 白線の左右間隔 | 60〜150% | 100% |
| ▲の上下位置 | 元の▲高さに対する−100〜+100% | 0% |

「左／右」は正面から見た配置。角度の正は時計回り。長さ・間隔・上下位置は追加設定の折りたたみ内にある。大きさと角度の組合せにより印が重なる場合はプレビューで調整する。NAVYとSOLDIERは別設定で、片方の変更がもう片方へ波及しない。初期状態では、▲を以前より大きく、線を以前より細くした。

## 保存・公開

既存の「この端末に保存」「編集前へ戻す」「公開設定に戻す」「公開用JSONを出力」「JSONを読込」「コピーしてGitHub編集」に形状も統合した。「形状だけ初期値へ」は選択モデルの形状のみを戻し、配色と他方のモデルは変更しない。

JSONスキーマ `compound-eye-appearance-v1` のトップレベルに任意の `visor` を追加し、`aegisEmber` / `aegisSoldier` それぞれの `triangleScale`, `barThickness`, `leftAngle`, `rightAngle`, `barLength`, `barSpacing`, `triangleOffset` を保持する。旧JSONに `visor` がなくても新しい既定を補完して読める。未知の項目、不正値、範囲外値は読み込みを拒否し、編集中の設定を壊さない。

公開用JSONを `public-appearance.json` としてGitHubでコミットすると、次のPages配信から選んだ形状も公開既定になる。端末保存・JSON出力だけでは公開は変わらない。認証なしの書き込みや、サイト内へのアクセストークン入力は行わない。公開revisionの更新を利用した旧端末設定の切替は従来通り。

## データの分離

調整するのはバイザーの3つのメッシュ用描画行列だけ。人体骨格、関節数、元頂点、関節速度・角速度・加速度・運動量スコア・マーカー判定へ書き戻さない。付帯JSONには `cosmetic_animation.visor_settings` と `shoulder_armor:false` を記録する。CSVは86列、AEGISは13関節、X Botは32関節を維持する。

新しい形状調整で、こめかみカメラ・1本アンテナ・タコメーター・SOLDIERの赤〜黄・配色の保護設定は変更しない。既存の走行／パンチは変更しない。

## 検証

現行単体テストは既存23件とバイザーの10件。削除済み肩装甲の旧テストを現行版の成功数に含めない。ブラウザ検証では、肩装甲なし、モデル別のリアルタイム調整、実スライダー／数値入力、保存後再読込、JSON実入出力、異常値拒否、取消・初期化、元の関節データ一致、1〜6個眼・単眼／双眼、縦画面を検査した。

WindowsのEdgeで実際のWebGL2を動かしてスクリーンショットと描画行列を確認。縦画面は表示エミュレーションであり、実機iPhone/Safari、HMD、GameSirの検証ではない。公開URLの確認結果は `docs/evidence/v60/public-verification.json` に保存する。
