# v59 — 中央▲・バイザー線の太さ統一・肩装甲

基準版：公開リポジトリの最新コミット `31a6e28`。直前に利用者が編集した `public-appearance.json` を引き継ぎ、ファイル内容とrevisionは変更しない。変更前は `backup-v58-before-v59-20261112` に保存。

## 今回の3点

1. **白い▲**：AEGIS NAVY / SOLDIERのバイザー上の2本線の間に、上向きの白い三角形を1つ追加。頭部ボーンに固定し、回転アニメーションは追加しない。既存の線の間隔を維持する。
2. **線の太さ**：元GLBの胸の左右2本の白線から、長軸に直交する線幅を計測し、その平均をバイザーの2本線へ適用。斜めの線の外接矩形の高さではなく、線自体の厚みを使う。計測値は左右とも約0.0097082モデル単位。以前の0.005から変更した。物理メートルへの換算値ではない。
3. **肩装甲**：左右の肩にグレーの面取り風の縁を持つ装甲を追加。上部と外側の段重ねを持ち、前・内側は開放する。左はL_UpperArm、右はR_UpperArmへ追従。身体のボーンや既存メッシュを変更せず、腕上げ・パンチ等で肩とともに動く。

肩装甲だけの描画行列から継承スケール／せん断を除き、動いている関節の取付位置を保持する。元の身体アニメーションに含まれるスケールで装甲まで伸びないようにした。この処理は描画用行列だけを変更し、骨格・計測・スコアの行列へ書き戻さない。

## 配色と既存機能

中央▲は既存の「バイザーの2本線・▲」グループで、肩装甲は「装飾・肩装甲・金具・アンテナ」グループで編集できる。新しい設定項目やJSONスキーマを増やしていないため、以前の配色JSONも使える。最新の公開配色をそのまま保持した。

SOLDIERの赤〜黄のケーブル／ノズルについて、元の色・位置・ボーンウェイトは変更していない。1本アンテナ、こめかみカメラ、メーター、白い胸の印、1個眼起動、静止2の削除、1〜6個眼と単眼／双眼、配色ウィンドウ、CSVを維持。
