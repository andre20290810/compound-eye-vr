# 人工複眼VR v45｜HMD表示、体幹固定、Safari向け不透明度合成

## 変更内容

- v44の試作回し蹴りはX Bot、AEGIS NAVY、AEGIS SOLDIERすべての動作一覧・描画関数・配信JSONから削除。パンチ、歩行、走行等は維持。
- 放射距離スライダーは腕脚に効き、3〜5眼の首〜胸／体幹を元の骨格投影位置に固定。6眼は体幹を含め従来どおり放射移動。
- 番号ラベルは「1：首胸」「2：左腕」など最短の形式にし、撮影角度・説明の長文を除去。
- HMD双眼VR／VRゲームでは、中央全身モデルをデフォルト非表示。GameSir LBでメニューを開き「中央全身：表示中／非表示」をAで切り替える。選択値は利用ブラウザのローカルストレージに保存。
- 中央全身の不透明度は通常・VR・VRゲームで共通の値を用いる。初期10％。旧20％の初期設定は10％へ移行するが、既存の独自の不透明度設定は極力維持。
- 楕円融合・個眼比較の「個眼の大きさ（楕円マスク）」を2.20倍に固定し、入力を非表示・無効化。全パーツ共通の放射拡大倍率は独立して使用可能。
- VRのRスティック上下操作範囲を拡張。左右を見渡せる従来操作に加え、上方の俯瞰から真下を見る位置まで調整できる。LBメニューの「見下ろし」でも俯瞰と正面を切り替えられる。

## Safari向けの不透明度の合成処理

v44までの中央全身と床グリッドは同じオフスクリーンRGBA画像へ描画されていました。合成処理ではアルファ値が0.75を境に床か人体かを推測していたため、SafariなどGPU／ブラウザのアルファ表現差に影響される可能性がありました。

v45ではオフスクリーンFBOを「床グリッド」「中央全身」「各局所個眼」に分割しています。合成シェーダーで床と人体を別々に扱い、中央全身にユーザー指定の不透明度0.00〜1.00を直接乗算するよう変更しました。楕円融合でも個眼比較でも、VR・VRゲームでも共通の不透明度を使います。

この方法はブラウザに依存する0.75の境界判定をなくします。ただしSafari実機での動作確認は未実施のため、修正の実効性は現場確認が必要です。

## 検証基準

- Windows EdgeのWebGL2で1〜6眼レイアウト／双眼VRをレンダリングし、JavaScriptエラーが発生しないこと
- 楕円融合・個眼比較の不透明度0％と90％で画面RGBに差があること
- 双眼VRの中央全身OFFでは中央用FBOが空、ONでは人体の不透明ピクセルを含むこと
- 既存のGameSirメニュー・X/Y長押し・15通りの配置保存・VRゲーム操作を維持
- RスティックとVRメニューの両方で俯瞰へ切替可能
- 3〜5眼の体幹の放射移動0、6眼は従来どおり放射移動
- 保存済み独自の中央不透明度、旧v44設定を読み込んでも楕円の大きさは2.20倍で固定
