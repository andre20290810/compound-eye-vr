# 人工複眼VR v44｜等倍・放射状配置とFBXモーション追加

## 1. 身体部位の映像を基準モデルの座標へ揃える

v43までは、6眼の骨盤などの一部が表示位置を固定していたため、2眼基準の全身モデルと上下の動きが一致しませんでした。

v44の標準「放射配置モード」では、**中心全身とすべての局所パーツを同一の投影行列・カメラ位置で描画**します。そのため各個眼の元位置は、2眼全身像に対して部位の関節が現れる位置と一致します。演技中、姿勢変化やカメラの上下方向の調整にも追従します。

- 放射距離0：部位を全身像の元位置へ等倍で重ねる
- 放射距離（0〜0.34）：2〜6眼の個眼位置を、眼数に応じて均等な角度に放射移動する
- 全パーツ共通倍率（0.60〜2.25倍）：局所映像のサンプリングスケールを一括変更する。1.00倍では中心全身像と投影倍率が同じ
- 3眼の放射角は約120度間隔、4眼は約90度間隔、5眼は約72度間隔、6眼は約60度間隔
- 各部位の元の骨格投影位置は異なるため、移動量・放射角は等しくても最終中心座標同士の距離が厳密に等しくなるとは限らない
- 楕円の幅・高さは通常は非表示。チェックをONにして必要時だけ個別調整する

放射モードをOFFにすると、既存のv43個眼レイアウトへ戻せます。旧v36等の保存値は破棄しません。

## 2. 回し蹴り（Roundhouse Kick.fbx）を追加

ユーザー提供のDriveファイル「Roundhouse Kick.fbx」（FBX 7700、約2.2MB、約2.5秒）からアニメーション回転キーフレームを抽出し、30Hzで76フレーム、22部位のJSONへ変換しています。

原本のFBXモデルおよびメッシュは新規には公開せず、**3アバターの既存メッシュへ適用するモーション曲線だけ**を公開しています。

- データ: roundhouse-kick.motion.json
- X Bot: `xbot_roundhouse`（元のMixamo系の骨格名へ対応して回転差分を重ねる）
- AEGIS NAVY / AEGIS SOLDIER: `armor_roundhouse`（骨盤・胸部・四肢を各AEGIS関節へ対応させ、回転幅を制限した試作リターゲット）
- 元FBXのHips並進は採用しない。固定した観察空間で動作を比較するため
- 元ファイルのSHA256はJSONの source_sha256 に記録
- 原本素材の権利・再配布条件は独立して確認できていないため、ユーザー提供データであることとライセンス未確認を明記

**注意:** 3Dモデル間では骨格・レスト姿勢・足先・腰の可動域が一致しません。今回のリターゲットは視覚的な動作確認用の試作であり、解剖学的に正確な関節制御、接地条件、熟練者の空手動作を再現すると保証するものではありません。

## 3. 計測パネル

v43の「表示用運動スコア（0〜100）」はグラフ上の主指標から除外しました。これは表示制御アルゴリズムの内部数値であり、動作の良し悪しを表していないためです。

- 主グラフ：関節の移動速度、または角速度の時系列（関節別）
- 副グラフ：主要身体部位ごとの**最大移動速度が発生した時刻**（点の位置で表示）
- 文章：数値ピーク、最大値の時刻、ピークが発生した部位の順序
- CSV：グラフに対応する関節ごとのモデル速度・角速度・ピーク値・ピーク時刻

これらの値は3Dアニメーションから計算しており、人体実測や運動技能の良し悪しを証明するものではありません。特に関節角速度にはキーフレーム補間の不連続が含まれる可能性があります。

## 4. 検証

放射距離0で個眼6つの基準中心座標がそれぞれ元の全身関節位置と一致すること、放射距離0.16で6個眼が等しい距離だけ移動すること、共通倍率1.5で全個眼のサンプリング倍率が揃うことを数値で確認。

6眼の腰～股関節を含め、視点の上下変更後も骨格参照位置を追従することを確認。FBX由来のモーションはX Bot・AEGIS NAVY・AEGIS SOLDIERの3アバターで関節行列が有限の値を保ち、動作時刻に応じて変化することを確認。
