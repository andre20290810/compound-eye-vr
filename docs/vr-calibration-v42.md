# v42｜通常ビューとVRビューの独立配置・コンパクト調整

## 新しい「調整画面」

通常画面の上部の**「調整画面」**を開くと、既存の設定・説明・実験計測などを一時的に隠し、以下だけを表示します。

- 3Dビューア（VR双眼プレビュー／通常ビュー切替）
- アバター・動作・個眼数（2〜6）・再生／一時停止の小さなツールバー
- 個眼の選択、左右・上下の位置、横幅・高さの倍率
- 必要時だけ開く「画角・距離・映像内位置」の詳細調整
- VR時のみ左右共通の中央寄せ、保存・初期化・公開用JSON出力

ビューアの水色円形ハンドルをマウスやタッチで移動すると、選択した個眼の左右・上下位置を更新します。

PCではビューアと調整UIを左右に並べ、モバイルでは小さいビューアを上に固定して、調整UIをスクロールできる構成です。

## VRと通常の違い

3D骨格モデルそのものは同一ですが、VRでは左右の描画領域を分割し、それぞれに眼位置オフセットと別の投影比率を適用します。またVR用のカメラ設定、個眼領域のマスク、VRフィット係数が通常画面と異なります。

このため**「通常ビューでちょうどよい位置」は、VRで同じ見え方を保証しません**。v42では、通常ビューの既存公開設定を一切書き換えず、VR用の個眼配置の計算値を別管理します。

- 通常用の個眼位置：`public-lens-defaults.json` と既存のローカル `compoundeye.v36.lensOverrides`
- VR用の個眼位置：`public-vr-lens-defaults.json` と新しいローカル `compoundeye.v42.vrLensOverrides`
- VR左右共通中央寄せ：v41からの `compoundeye.v41.vrAlignmentByAvatarAndCount`（15組の独立保存）

VR専用のレンズ初期値は `x=y=imageY=0`, `w=h=distance=fov=1` です。これに対して、公開用JSONの各アバター・眼数・個眼の設定が上書きされ、最後にブラウザへ保存したVR値が適用されます。

VRプレビューでは、ゴーグル用の左右2画面と同じ描画パス、局所カメラ、フィット係数を使用します。ただし**実機の画面の縦横比・ゴーグルのレンズ・装着位置や光学倍率までは再現できません**。最終的には実機のゴーグルで確認する必要があります。

## 保存と公開

「VR用に保存」は**今のアバター×個眼数**のカメラパラメータをブラウザへ保存します。左右中央寄せも同じ操作で保存します。変更していない他の14組のデータは維持します。

「VR設定JSON出力」では、`public-vr-lens-defaults.json` を書き出します。共有の公開デフォルト値にするには、この出力をGitHubリポジトリ直下の同名ファイルへ反映する必要があります。ローカル保存だけで他の端末の公開初期値は変わりません。

「この個眼を初期化」は選択した個眼のVR（または通常）調整だけを初期化し、「この眼数のVR配置を初期化」は現在のアバター・眼数のVR局所カメラ設定と中央寄せを初期状態に戻します。保存前は元の保存値を破壊しません。

## 研究としての未検証点

この方式は同じ3Dアニメーションから身体部位の映像を複数描画し、表示を再配置するものです。**個眼数を増やしたこと自体が新たな実測運動情報を生み出すわけではありません。**

有用性は、動作順序の識別率、反応時間、主観的な負担を通常の単一視点・固定5眼・適応型5眼で比較する予備実験で検証する必要があります。v41の実験計測は3Dアニメーション計算ログであり、人体実測や技能向上の効果ではありません。
