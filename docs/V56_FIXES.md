# AEGIS追加6項目 — 実装・実ブラウザ検証

基準版：v55公開コミット `4147eb0c3b538e5ff2ca62f48b0e3e5369084461`。復元タグ：`backup-v55-before-v56-20261111`。

## 反映した内容

1. **走行**：X BotのBoxer_Runから、バインド軸を合わせた左右の股関節・膝の動きを256点で取得。5次までの周期成分で連続曲線にし、周期全体の振幅をAEGIS用の範囲へ調整した。各フレームの脚角度を上限で切り止める旧経路は走行で使わない。ループ端の曲線の位置・速度・加速度は連続。旧版のスキニング／剛体装甲分割を維持し、歩行とパンチの経路は変更しない。
2. **こめかみアンテナ**：左右各1本を追加。頭部ボーンに追従し、画像の印に合わせて後上方へ伸びる。新しい人体関節は増やしていない。
3. **紺色化**：背面取付板、縦レール、ノズル外殻の近黒色を青紺の材質へ変更。照明による陰影は残る。
4. **起動時1個眼**：初期state、保存済みの旧既定設定からの復元、初期設定へ戻す処理を1個眼へ統一。手動での2〜6個眼切替、双眼表示は残す。
5. **静止2**：待機姿勢を固定し、2本の白いバイザーバーをそれぞれの中心で時計回りに回す。方向はアバターの正面から見た方向。原アニメーション時刻で1周4秒。通常の再生速度0.65の場合は実時間の周期が長くなる。別動作では元の横棒へ戻る。動作選択、比較、4秒の時間スライダーへ接続した。
6. **タービン付きジェット**：背面の固定吸気リング、回転羽根、軸、冷却リング、ボルト、リブ、点検パネル、ノズル内部の回転羽根を追加。左右吸気2基＋左右ノズル2基の4ローターが実際に回る。人体骨格とは別の描画行列で、停止・原時刻シークと同期する。

NAVYとSOLDIERの両方に適用。以前のナイフ削除、脚の剛体面、魚眼既定ON、版番号なしのタイトル、補足欄への集約は維持した。初めて計測欄を開いた際に現在の動作がX Botへ置き換わる経路も修正し、静止2を保ったまま解析を開始する。

## 走行の比較

旧版は数学的に完全な停止だけではなく、膝の屈曲角がほとんど変わらない区間を含んでいた。検査では同じ0.633333秒の周期を240区間に分け、XYZ回転のX屈曲角の変化率を比較した。5度/秒未満を「ほぼ静止」の工学的検査条件とした。この閾値は技能や自然な人体運動の基準ではない。

| 膝 | 旧版の該当区間数 / 240 | 新版 / 240 | 最長該当時間：旧→新 |
|---|---:|---:|---|
| 左膝 | 68 | 1 | 89.72 → 2.64 ms |
| 右膝 | 71 | 2 | 145.14 → 2.64 ms |

上限角で固定される時間を除くための連続化であり、足裏の物理接地・衝突シミュレーションを追加したものではない。AEGISに足首・つま先の独立ボーンはない。X Botそのものの動作・骨格は変更していない。

## 実施した検証

- Node単体テスト22件成功。
- 既存機能の実ブラウザ回帰14項目成功（86列CSV、旧数値互換、骨格JSON、時刻同期、同一X/Y差分、保存配置、1〜6個眼・単眼／双眼、Gamepad API模擬入力）。
- 前回のUI／モデル検証8項目成功（魚眼既定、補足集約、ナイフ削除、剛体脚面等）。
- 今回の追加検証9項目成功（1個眼起動、旧保存値ありの起動、静止2、アンテナ／ローター行列、紺材質、走行比較、CSV／化粧部品の分離、縦画面、実行時エラーなし）。

合計：単体22件＋ブラウザ31項目。ブラウザはWindows上のデスクトップEdgeのWebGL2を実行し、GPUバッファ／画面画像を取得した。以前のWebGLを模擬したローカル検証とは異なる。縦画面はデスクトップブラウザのモバイル表示エミュレーションであり、実iPhone検証ではない。

両モデルのアンテナ・背面・静止2の0/.5/1秒と走行8局面をPNGで記録。静止2は頭部拡大画像で横→右下がり→縦の回転を確認した。脚領域は歩行・走行それぞれ40時点で再検査し、装甲面の辺長比は数値誤差内で1。布／ケーブルを含め2倍を超える辺はない。

## 未検証範囲

実機HMD、実機GameSir、実iPhone/Safari、衣服・装甲の衝突、身体技能学習効果は未検証。タービンは外観アニメーションで、飛行操作や推進力を加えるものではない。素材・人体関節・表示用部品を混同しないよう、CSVは引き続き86列、AEGISは13関節、X Botは32関節。化粧部品の動作定義はJSONの `cosmetic_animation` に分離した。

## 追跡・再実行

内部版はv56。タイトルには版番号を出さない。`build-manifest.json` が実装コミットと配信ファイルハッシュを持つ。追加ソースは `aegis-motion-v56.js`、`aegis-details-v56.js`、`aegis-runtime-v56.js`。既存のバンドル処理で自己完結HTML内と照合する。

```sh
npm test
npm run check
npm run test:visual
npm run test:browser
npm run verify:public
```
比較時は `V55_BASELINE_DIR` を復元タグの作業ツリーへ設定。既存X Bot数値互換の比較時は `V53_BASELINE_DIR` をv53作業ツリーへ設定する。ブラウザには必要に応じて `BROWSER_EXECUTABLE` と `PUPPETEER_MODULE` を指定できる。
