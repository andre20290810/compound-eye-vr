# 人工複眼VR v46｜2眼0％・3眼再構成・4眼水平比較

## 1. 中央全身の不透明度

- 工場初期値：2個眼は **0％**、3～6個眼は **10％**。
- 2個眼でも左右半身の **2つの独立局所カメラ映像**を描画する。全身モデルを0％にしても床だけの空画面にならないようにした。
- 個眼数変更時は、利用者が不透明度をまだ手動変更していない場合のみ各眼数の初期値を適用する。
- 利用者がスライダーで20％や35％などへ変更した場合、その値は眼数を変えても維持する。「公開用設定を保存」した場合には手動変更フラグも一緒に保存する。
- 旧v45で10％や20％を初期設定として保存していた場合は、新しい眼数別初期値へ移行する。別の値をユーザーが指定していた場合はできる範囲で保持する。

## 2. 3個眼：旧4個眼をベースにした構成

v45の4個眼の発想「左右上半身・左右脚を個別に観察」を3カメラに再構成。

1. 左上半身（頭部・左腕など）
2. 右上半身（頭部・右腕など）
3. 両脚（左右脚を1つのカメラで描画）

**注意:** 4つの独立した映像を3眼へそのまま移すことはできないため、下半身は1つの局所カメラにまとめた。3眼を装いながら4本のストリームを生成する方式にはしていない。

## 3. 新4個眼：左右2列×上下2段

- 上段：左上半身（1）／右上半身（2）
- 下段：左脚（3）／右脚（4）
- 中央全身の **胸の投影高さ**を上段の共通の高さとする。
- 中央全身の **左右膝の投影高さの平均**を下段の共通の高さとする。
- 上段と下段の両方で、左右の中心を `0.5±fourEyeGap` に配置。
- 単一の「4眼・水平間隔」スライダーで上段・下段の左右距離を同時・対称に調整する（範囲0.26～0.43、デフォルト0.32）。
- 個眼マスクの横半径に上限を設け、中央全身の比較対象と重複しにくくする。
- スライダーは通常の個眼数選択欄、個眼レイアウト調整パネル、コンパクト調整画面から操作可能。
- 値は `compoundeye.v46.fourHorizontalGap` に端末保存し、再読み込み時に復元。
- 4眼は放射方式ではなく、この水平方式を常に使用。他の眼数の放射配置設定は維持する。

## 4. 影響範囲・確認

- X Bot・AEGIS NAVY・AEGIS SOLDIERの3モデルで3眼・4眼を確認
- 3眼は実際に3つのカメラと対応する部位マスクで描画
- 4眼は4つのカメラと部位マスクで描画
- 4眼の上2つの中心Yは一致し、下2つの中心Yも一致
- 左右中心Xは0.5に対して対称
- 他の5・6眼の構成は維持
- GameSir、15種類のVR配置保存、モーション、実験計測の回帰テストを実施

**留保：** 実機HMD／iPhone Safariの表示確認は未実施です。3眼の脚部をまとめた方式が研究評価として適切かは、後続の知覚実験で確認する必要があります。
