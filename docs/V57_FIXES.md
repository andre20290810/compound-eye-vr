# AEGIS v57 — グレー装飾・アンテナ・タコメーター・こめかみカメラ

基準版は公開v56 `e411b6a`。変更前のコードと素材を `backup-v56-before-v57-20261111` タグに保存した。NAVY / SOLDIERの双方に適用している。

## 反映した仕様

| 項目 | 実装 |
|---|---|
| 静止2の削除 | 通常・ビューアー・比較用等の動作候補から削除。過去の選択IDを渡した場合は既存の「静止・呼吸」へ戻す。回転するバイザーバーの描画を廃止。 |
| アンテナ | 頭部局所座標の水平面を基準として、70°から90°の間で小刻みに上下する左右各1本。基準形状70°、時間による角度は80°を中心に最大±10°。 |
| メーター | 2つの背面ファンを撤去し、固定目盛り・円形文字盤・往復する黄色の針を持つタコメーター風表示へ変更。ノズル内の回転羽根も撤去。指針は1周するファンではなく有限角度内を往復する。 |
| こめかみカメラ | 左右それぞれ3基の小型レンズをグレーのくぼみ付きハウジングに組み込み、頭部へ追従させた。両側計6基。撮影・録画を行う実カメラ機能ではなく外観パーツ。 |
| 黄色のバー | バイザー上の2本の白い横棒を黄色に変更。常に横向きの固定表示。 |
| グレー化 | バイザー、背面ロケットの筐体・ノズル・支柱・リング、こめかみ部品、装飾金具・関節カバー等をグレー化。ベースの身体・服の紺色は保持。黄色のバーとメーターの指針は指定アクセント色。 |
| SOLDIERの色保護 | 既存の赤〜黄の発光ケーブルとノズル発光は、元の頂点色・位置・ウェイト・発光式をそのまま維持。NAVYの同種装飾はグレー仕上げ。 |

## 計測からの分離

アンテナとメーターの可動部には、人体骨格とは別の描画用行列を使う。AEGISの骨格は13関節、X Botは32関節のまま。`md.bones`、`md.world`、`md.poseRot` は装飾の更新で書き換えない。運動量スコア・部位マーカーの選択・関節速度／角速度のCSVへ装飾の動きを追加しない。

CSVの付帯JSONには `cosmetic_animation` として角度範囲・時計・除外条件を明示する。メーターは変化する見た目を作る装飾で、実測のエンジン回転数や身体運動量の表示ではない。身体アニメーションの元時刻に同期するため、再生停止時には装飾も止まり、シークすると同じ表示を再現する。

## 維持した機能

v56で連続化した走行、v55の脚の剛体装甲分割、パンチ・歩行、初期1個眼、手動1〜6個眼、双眼時の魚眼既定ON、保存設定、GameSir操作、計測／CSV、版番号を出さないタイトル、ビューアー直下の更新日時、補足の最下部集約を維持した。

## 検証

- **単体23件成功**：既存運動学・脚の構造の15件、新しい装飾と走行曲線の8件。20秒間のアンテナ角度、三角形とウェイトの整合性、針の有限角度、左右各3カメラ、固定黄色バー、SOLDIER色保護方針を含む。
- **ブラウザ33項目成功**：従来機能14、前回UI・脚検証8、今回の追加11。WindowsのEdgeで実際のWebGL2を起動して描画・GPUバッファを検査した。
- **v56との10動作の数値一致**：両AEGISの呼吸・パンチA・歩行・走行とX BotのパンチA・走行について、全関節位置・速度・加速度・スコア等の既存列が完全一致。今回の変更は身体の動作を変えていない。
- **SOLDIER発光パーツ**：ケーブル／ノズルの色・位置・ウェイト配列と発光計算式がv56と一致。
- **脚の辺長検査**：歩行・走行各40時点。剛体装甲面の辺長は数値誤差内で1、布／ケーブルを含め2倍を超える伸びなし。
- **画面記録**：両モデルの正面／左右こめかみ、0秒・0.3秒・1.2秒のメーター、走行と縦画面を保存。目視でグレー、黄色、SOLDIERの赤〜黄、3つのカメラ、メーターの針の変化を確認。

歴史的v56の単体テストはソースとともに残したが、v57の `npm test` は現行対象だけを明示的に選ぶ。削除済みの静止2／ファンを現行版の合格項目として数えない。

## 確認できていない範囲

実機iPhone/Safari、実機HMD、実機GameSirは未検証。縦画面はデスクトップEdgeの表示エミュレーション。実際の推進力・RPM計測・カメラ撮影機能を追加していない。身体の動きの自然さや技能学習効果の新しい評価ではなく、外観と実装上の回帰検証である。

## 公開と再実行

内部版はv57。タイトルは「人工複眼シミュレーションシステム」のまま。`build-manifest.json` の `source_commit` とソースSHA-256で配信物を照合する。元GLBを残し、実行時の装飾加工を `aegis-v57-grey-tachometers-camera-triples` で記録。新規ソースは `aegis-details-v57.js`、`aegis-runtime-v57.js`。

```sh
npm test
npm run build
npm run check
npm run test:visual
npm run test:browser
npm run verify:public
```

ブラウザ／baseline環境変数は既存の実行方式を引き継ぐ。前版比較は `V56_BASELINE_DIR`、X Botのv53互換検査は `V53_BASELINE_DIR` を指定する。
