# 人工複眼シミュレーションシステム｜v51変更記録

## 画面タイトル

ブラウザタイトルとページ見出しは、バージョン番号や技術説明を並べず、`人工複眼シミュレーションシステム 更新：YYYY/MM/DD/HH:mm` へ変更。時刻はビルド時の日本時間。内部ログ・ビルドマニフェストには実装バージョン `v51` とコミットIDを保持する。

## 1眼（中央全身）の復活

通常の1画面ビューア、HMDの左右双眼表示、VRゲームのいずれにも **「1眼：中央全身のみ」** を追加。

- 1眼では局所カメラ映像を生成しない。中央全身のみを不透明表示し、従来のVR用「中央全身を隠す」設定にかかわらず表示する。
- 1眼で主観表示を選んでいた場合も、全身観察を優先して通常の外部視点で描画する。
- 2眼の初期中央不透明度0％、3〜6眼の初期10％は維持。
- 1眼では放射距離・個眼の部位選択など意味のない調整UIを隠す。
- 旧2〜6眼の眼数別保存値とVR左右寄せの設定は削除しない。
- 個眼数を循環する通常のショート操作は1→2→3→4→5→6→1。X長押しによる従来の10秒ごとの自動切替は2〜6眼のまま維持。

## 個眼マーカーの表示先

従来は骨格の中央全身用カメラへの投影位置を、局所映像のマーカー位置にも流用していたため、見た目の関節位置にずれが生じた。

v51では、**個眼の実際の描画カメラ**、個眼の焦点オフセット、サンプリング倍率、マスク楕円の範囲、双眼表示の補正倍率を用いて、マーカー座標を逆算する。

- **位置：個眼**：それぞれの複眼部位の映像上へマーカーを描画。単眼・双眼とも同じ計算を使用
- **位置：全身**：中央全身上へ通常の関節位置を描画
- 単眼ビューアでは右上に「位置：個眼／位置：全身」ボタンを追加
- HMD表示では各眼に同じ切替ボタンを表示し、GameSirのL3でも切替可能
- 局所映像に表示するマーカーは、選択個眼に対応する実際のメッシュスキニング関節で絞り、楕円領域内（端の約12%を除外）だけに表示
- 個眼単独表示・比較差異リングでも同じ局所投影を使用
- 1眼は全身のみなので、マーカーも中央全身で表示

既存の運動量スコア（初期閾値30/100、調整可能）と個眼別マーカーON/OFFを維持する。

## 4眼上半身の高さ揃え

4眼の左右上半身は、カメラ映像の縦方向の元座標を**中央全身の胸部の高さ**に揃える。左右上半身は同じ高さに固定し、ユーザーの水平距離の調整はX座標のみに作用させる。3Dモデルのポーズ・骨格の動作変化に追従し、単眼・双眼双方で適用。

## HMD中のクイック操作

HMDの左右両眼に、短い操作ボタンを同じ配置で表示：

- **眼2→3** 等：次の個眼数へ（1〜6）
- **モデル↻**：X Bot → AEGIS NAVY → AEGIS SOLDIER の順に切替
- **■ON/OFF**：マーカーの表示切替
- **個眼／全身**：マーカー位置の切替
- **設定**：メニューを開く

GameSirでもメニュー不要で切替可能：

| 操作 | 内容 |
|---|---|
| X短押し | 次の眼数へ（1〜6） |
| X長押し | 既存の2〜6眼自動切替のON/OFF |
| Select（Button 8） | マーカーON/OFF |
| L3（Button 10） | マーカー位置切替 |
| R3（Button 11） | モデル切替 |
| LB | メニューを開く |
| Y長押し | 現在のアバター・眼数別VR寄せ位置を保存 |

実機GameSirでは機種・接続モードでボタン番号が異なる場合があるため、Windows EdgeのGamepad標準マッピングによる模擬試験を実施した。

## VRメニューと終了ボタン

従来20個以上の操作項目が縦に並び、画面内で押せなくなることがあったため、**最大9個の3列×3行のメニューページ**へ整理。

- 基本／眼数／表示設定／その他のページに分割
- 全ページの左上に大きい緑の「ゲームへ戻る」、上段の2番目に赤の「VR終了」を配置
- GameSirの方向キー・左スティックで選択し、A決定、Bでゲームへ戻る
- メニューを閉じたVR画面では、終了ボタンを端から内側へ寄せて押しやすい位置へ調整
- HMD表示ではモデルの詳細説明、関節数、実験の長文ステータスを隠し、最小限のボタンのみ表示

## 動作・互換性確認

Windows Edgeを使ったブラウザ自動テストで以下を確認：

- 1眼時：通常ビューアの全身だけの描画FBO 2枚、双眼時4枚、局所個眼0個
- 2・4・6眼への切替で従来の個眼カメラ数が維持されること
- 4眼上半身の元映像の高さと表示先の高さの一致（単眼・双眼）
- 4眼の右上半身を選択した場合、その局所映像のメッシュ・マスク内にマーカーが現れること
- 通常と双眼のマーカー位置切替（個眼／全身）と個眼単独表示
- GameSir模擬入力でX短押し・Select・L3・R3が動作すること
- 3列×3行のメニュー、眼数の独立ページ、ゲームに戻る操作
- 既存の15種類のVR寄せ保存、X/Y長押し、GameSir移動、時刻同期解析、最大5動作比較、CSV／JSON出力の回帰テスト

**未実施**：iPhone Safari・実機GameSir・HMDゴーグルでの視認性と実操作テスト。各ブラウザのボタン配置やフォント可読性、長時間稼働時のパフォーマンスは今後確認が必要です。
