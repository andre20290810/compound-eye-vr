# 人工複眼VR v43｜単眼／双眼表示と動作グラフ解析

## 画面仕様

通常画面は、単眼（1枚のビューア）で「2個眼 · 通常立体視 · 角度一致」を初期表示します。「3D閲覧」「VRゲーム」は単眼のビューア内で切り替わり、「双眼表示」を押したときだけHMD用の左右2画面を開きます。VR終了時は単眼画面へ戻ります。個眼数2とHMDの左右眼を混同しないための設計です。

- 上部の不要な説明文を削除
- 旧「VR左右半身の中央寄せ・アバター×個眼数別保存」パネルを画面から非表示にし、以前の設定データとコントローラー操作は保持
- 「個眼レイアウト調整」の下に「実験計測」を移動
- コンパクト配置調整、VR左右設定、既存アニメーション、GameSir操作を維持

## 実験計測のグラフ

従来の記録開始・停止と複数のCSV／JSON出力だけでは運動特徴が判断しづらいため、選択した動作モーションの時系列グラフ・数値・解釈を先頭に追加しました。従来の機能は「詳細ログ」に折りたたみ、既存のアバター・動作選択ボタンを重複表示しません。

グラフは実際の人体運動ではなく、同梱3Dアニメーションの関節計算値です。

- 解析元: X Bot / AEGISの内蔵アニメーション・簡易プロシージャルモーション
- 解析頻度: 表示時間軸に沿って理論上約30サンプル／秒。現在の描画FPSや実際の人の運動計測ではない
- 同じモーション・再生倍率から関節姿勢を再サンプリング
- 指標: 関節のモデル相対移動速度（モデル単位/秒）、関節回転の角速度（rad/sを度/秒に換算）、既存の表示制御用運動スコア0〜100
- 上位3関節の時系列、上位6関節の最大表示スコア、選択した関節の時系列を表示
- 解析対象、サンプル数、ピーク関節、ピーク速度、ピーク時刻を文章で示す
- 表示用スコアが飽和している場合は、差を識別しづらいことを通知
- グラフに対応する全関節・全サンプルの計算値をCSVで保存可能

## 重要な限界

計算に使う関節座標はアバター固有のモデル座標であり、較正済みの実測メートルではありません。角速度のピークには補間や骨格計算の急変が混じることがあります。「運動スコア」は表示選択用のスコアであり、熟練度・運動の正しさ・身体能力の評価ではありません。

待機モーションなど通常の表示制御で動きの検出を省略する動作も、解析時だけ関節座標と回転の微小な差分を評価します。通常のマーキングや自動拡大の条件には影響させません。

このグラフからわかるのは、選択した3Dアニメーション内の運動部位・時刻・数値的ピークです。人工複眼表示によって人間の動作認識が改善したという証拠ではありません。

## 出力CSV

グラフ用CSVはUTF-8 BOM付き、CRLF改行です。次の16列を含みます。

source_type, avatar_id, motion_id, eye_count, playback_factor, display_time_s, animation_time_s, joint_name, joint_id, linear_speed_model_units_per_s, angular_speed_rad_per_s, angular_speed_deg_per_s, display_motion_score_0_to_100, joint_peak_score_0_to_100, joint_max_linear_model_units_per_s, joint_max_angular_deg_per_s

実測データの取得、正解動作との一致判定、知覚実験の正答率・回答時間・主観的負担の推定、SINDyによる実運動法則の推定はこの版では実装していません。
