# v63 — 視覚的な可読性とAEGISパンチBの改善

基準版：v62実装 `01c131b`。バックアップタグ `backup-v62-before-v63-20261112`。配色・バイザーの公開プリセットは一切変更していません。

## AEGISパンチB：頭・脚の過回転と手首・拳
v62の段階では、X Bot32関節をAEGIS13関節に置換したまま過大な頭部・脚部の動きが残り、専用拳が大きなグローブ状でした。v63ではX Bot Cの両腕のワールド方向と動作時刻を保持しつつ、骨盤・胸・頭・大腿・下腿を既存AEGISパンチAの安全な下半身・体幹姿勢へ切り替えます。腰を変更した後の上腕角度を逆変換して補償するため、上腕と前腕の動きが失われません。拳は元の手首ボーンと一致する軸へ向け直し、細身の手首カバーと小型の握り拳へ変更。指の独立ボーンは追加せず、パンチBだけ旧開いたグローブを隠します。目標はゲーム内描画での破綻低減であり、人間の空手技能の物理的再現や接触シミュレーションを保証しません。

## YBotの色
全身を彩度の強いピンクに塗りつぶす処理を廃止し、X Botの元のシェーディングを維持する淡い青みのあるスチールグレーへ変更。骨格・骨長・動作差分設定・CSVの観測値は同一です。

## 運動連鎖の表示
画面下部に「① ピークの発生順と隣接時間差」を先に配置し、代表ピーク順をシンプルな時刻カードとms間隔で示す。同時刻のピークは「同時刻」と表示する。各部位は**横長の時間帯バー**で緑（増速）・橙（減速）・灰（低活動）を見せ、黄の菱形で**代表ピークを1つ**表示する。Yは色を変えず輪郭バーと菱形で区別。以前の1サンプル1円を多数並べる表示は廃止。右端の数値は短い表記と単位へ整理し、MU/s=モデル単位/秒を常時表示する。ピークを押すと従来どおり元アニメーション時刻へシークする。波形・X/Yの再計算・JSON/CSVエクスポートは維持。

## 3Dマーカー
解析用3Dラベルが人体を覆うのを避けるため、長い文字ラベルを廃止。デフォルトではタイムラインから3Dへ描かず、利用者が明示的に「3D位置に小さな点を表示」をONにした時のみ、関節に小さな色点を表示する。点はタイトル/状態IDで参照できる。状態判定はタイムラインと同じ運動学関数を使い分岐させない。通常の既存マーカー設定・スクリーン内判定を停止するわけではない。

## 研究上の制約
表示は位置・姿勢から計算した運動学的特徴です。力・関節トルク・エネルギー伝達・因果関係・技能の優劣を示しません。XBot–AEGISの異骨格比較禁止は継続。YBotの同一骨格、変更前後の運動学再計算、CSV 86列と各動作の既存計測処理は保持。
