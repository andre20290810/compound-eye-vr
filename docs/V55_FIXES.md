## 脚の検証

旧版と新版で同じ元アニメーション・同じ40時点／動作を使用。モデルのカメラ、透過率、速度を変えて不具合を隠す方式ではない。描画時と同じGPUバッファの頂点・スキン行列を使い、脚領域（元のy≦0.74モデル単位）の辺長を検査した。極小・退化した辺は1e-5モデル単位を下限として除外し、同じ条件を両版へ適用した。

旧版のpants領域では歩行で最大約17.50倍、走行で約23.02倍の辺長が確認された。新版ではpants・boots・脚のvest hardwareの最大辺長比は約1.0000001で、数値誤差内で元の寸法を維持する。柔軟なケーブルと布の曲げ変形は残るが、今回の40時点の検査で脚領域に2倍を超える辺はない。この結果は描画不具合の検査であり、人の動作の良し悪しや物理的な衣服シミュレーションの検証ではない。

関節ごとに面を分割する際、切断前後の静止表面積が一致することを単体テストで確認している。元の面を単に非表示にしたり、脚全体を別モデルに差し替えたりはしていない。接合部は装甲・機械的な関節として分かれて動く。

詳細：[変形量と比較画像一覧](evidence/v55/geometry-inspection.json)。代表画像はNAVY/SOLDIERそれぞれの歩行・走行の正面／側面、およびナイフ除去とジェット追加の背面／斜め背面を記録している。

## 版と復元

内部版はv55だが、表示タイトルには版を出さない。コードは `build-manifest.json` の `source_commit` と各ファイルSHA-256で確認する。元GLBバイト列は保持し、実行時のモデル加工を `aegis-anatomical-skin-jet-v55-001` と実装コミットで追跡する。CSVの素材版・動作改訂IDにもv55の加工を記録し、以前の描画素材と混同しない。

変更前のv54は `backup-v54-before-v55-20261111` タグ。読みやすい追加ソースは `aegis-geometry-v55.js` と `ui-v55.js`。配信HTMLは従来同様、必要なJSを内包する自己完結形式。`npm run build` と `npm run check` で埋込版と分離ソースを一致させる。

```sh
npm test
npm run check
# Chrome/Edgeを使う場合は BROWSER_EXECUTABLE を指定する。
# 比較画像は V54_BASELINE_DIR に旧v54の作業ツリーを指定して作る。
npm run test:visual
npm run test:browser
npm run verify:public
```
