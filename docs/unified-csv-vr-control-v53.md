# 人工複眼シミュレーションシステム：v53改修記録

## 統合された「選択動作・全関節CSV」
- 現在のアバターと動作を選び、実験計測内の「選択動作・全関節CSV」を押すと、録画操作なしで元アニメーション時刻に沿った数値を1ファイルへ出力。
- X Botは指を含む32スキニング関節、AEGIS NAVY／SOLDIERは13関節。
- 29列：アバター・モーションID、素材ID、骨格ID、元時刻、サンプル間隔、関節名・ID・日本語名、ルート相対位置X/Y/Z、移動速度、角速度、移動加速度、角加速度、表示用運動量スコア（0〜100）、座標系・単位・品質警告。
- モデル計算値は約30Hzで等間隔再サンプリング。指標は人体実測ではなく、位置はモデル単位、速度はモデル単位/秒、角速度はrad/秒、加速度はモデル単位/秒²。
- 運動量スコアは元の表示ヒューリスティックに相当する係数でサンプリング曲線から再計算。技能の優劣判定ではない。
- 比較用の既存CSV／JSON、実時間の時系列記録機能は引き続き使用できる。

## AEGIS走行時の脚部
- X Botの走行周期と左右脚の交互運動を維持。
- 13関節の装甲では膝が約85〜87度まで回転しており、脚の中間部をゴムのように変形させやすかった。
- 下腿を主に屈曲軸（X軸）の回転に限定し、走行で最大約64度、歩行で約68度まで制限。上腿も走行約54度・歩行約60度へ制限。
- 膝の長軸ねじりを抑え、独立ボーンがない足首・つま先の回転を下腿へ加算する旧処理を廃止。
- メッシュの再リギングや接地IKは実施していないため、全フレーム・全視点で物理的に自然な運動を保証するものではない。

## AEGISパンチAの拳の正中線
- 胸・腰の回転に引きずられないよう、アバター正面の基準座標に狙い位置を固定し、骨盤・胸部クォータニオンを逆変換して肩ローカルIK目標へ変換。
- 腰・胸の捻りと踏み込みは維持。
- 両AEGISの最大伸展付近で、拳の横方向と頭部中心の差は約0.009モデル単位、顎側へ約0.055モデル単位下、頭部より約0.393モデル単位前方に配置されたことを確認。
- 拳の皮膚・装甲表面と手ボーン原点は一致しない可能性があり、人のストレート技としての適切性は未検証。

## 双眼VRの10秒自動切替
- 双眼HMDで **1→2→3→4→5→6→1** を10秒ごとに循環可能。
- 左右のクイック操作「自動10秒」でON/OFFを切り替え。GameSirのX長押しでも同じ動作。
- 通常の単眼では従来の2〜6眼循環を維持。実験条件A/B中は自動切替を禁止。

## VR操作の重なり解消・GameSir操作
- HMD左右それぞれのボタンを5列×2段（合計10個）で配置。画面幅740px、844px、1200pxの各表示でボタン同士の重複なし。
- 旧固定VRボタン「双眼→単眼」「メニュー（LB）」「正面0°」は新操作列と重なるため、HMD中に非表示。機能は設定メニューに保持。
- GameSir STARTでクイックボタン選択開始。十字キー／左スティックでフォーカス移動、A決定、B終了。
- 通常のVRゲームの移動は変更せず、クイック選択中だけ移動操作を無効にする。
- 終了ボタンは画面下部の内側に配置。残る操作は「眼数送り／自動切替／番号／マーカー／モデル／動作／部位／指標／マーカー位置／設定」。

## 双眼の番号の表示・非表示
- クイックボタン「番号ON／番号OFF」を単眼・双眼共通の番号表示状態に接続。
- 左右両眼で同時に切替。ブラウザのローカル設定に保存し、通常／VRの切替や再読み込み後も保持。
- 番号を非表示にしても、選択済みの個眼やマーカー設定には影響しない。

## 自動テストと制約
- X BotパンチA：32関節×34時刻＝1088行、AEGIS NAVY走行：13関節×20時刻＝260行、AEGIS SOLDIERパンチA：13関節×51時刻＝663行。いずれも29列の統合CSVが出力された。
- AEGISの走行では両下腿の屈曲が最大約64度になり、骨格変換行列が有限値であることを確認。
- 双眼で自動切替6→1→2、番号ON→OFF→ON、GameSir START→方向選択→A決定→B終了を確認。
- Windows Edgeのブラウザテストに基づく。Safari・実機GameSir・HMDゴーグルでの最終的な視認性・操作性は未検証。
