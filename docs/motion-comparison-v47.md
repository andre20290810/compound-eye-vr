# 人工複眼VR v47｜モーション時刻同期・2動作比較と個眼表示改善

## 1. 3・4眼の脚部表示と4眼の水平間隔

- 3眼の両脚と4眼の左右脚について、切り出し楕円の縦方向を拡大して、足首・かかと・つま先を確認できるようにした。
- 下半身の表示中心を膝の投影位置より少し上に置き、左右脚は同じ高さに配置する。
- 4眼の水平間隔は **0〜0.49（正規化UV）**。0では左右が中央で重なり、0.49では画面端近くまで離せる。極端な値では重複や画面端切れが起こり得る。共通の楕円サイズ調整とは独立する。
- 2〜6眼、AEGIS／X Bot、VR・GameSir操作、各眼数の不透明度の仕様は維持する。

## 2. グラフ・3D・個眼映像の時刻同期

- 折りたたみ式「実験計測」内に「時刻同期・2動作比較・運動差分（v47）」を追加。
- 時系列グラフ上の任意位置を選ぶと、**元アニメーション時刻**に対応する3Dモデル・全個眼を停止・表示する。
- 再生／一時停止、前後コマ送り、0.25・0.50・1.00倍再生を用意。
- グラフの縦カーソルと時刻スライダーは実際のアニメーション再生位置に追従。
- 運動開始時刻と最大速度時刻は別の記号で表示。各ピークを選ぶと当該関節と時刻を選択する。

**時間軸:** 解析値はモデル本来のアニメーション時刻。画面描画のperformance.nowとは区別。元データはGLBのキーフレームまたはプログラム生成ポーズであり、元FBX／GLBの収録Hzは不明。描画値を約30Hzの等間隔で再サンプリングしている。

## 3. 運動特徴量

選択可能な時系列指標：
- 関節移動速度：モデル単位/秒
- 関節角速度：rad/秒（グラフは度/秒へ換算）
- 関節移動加速度：モデル単位/秒²
- 関節角加速度：rad/秒²（グラフは度/秒²へ換算）
- ジャーク：モデル単位/秒³（位置の3階時間微分のノルム）

運動開始は「最大速度比15％（調整可）」かつ原則3連続サンプル（調整可）で検出。微小速度の絶対閾値も併用。最大速度・最大加速度とその到達時刻、減速開始の候補、速度ピーク数、参考のジャークRMSと推定SPARCを計算する。

**制限:** キーフレーム補間やプロシージャル動作由来であり、実測の収録Hzや測定誤差が確認できない。特に加速度・ジャーク・SPARCはスムージング（なし／3点／5点）の影響が大きい。SPARCは10Hz以下の探索的スペクトル弧長で、検証済み臨床指標の代用ではない。

## 4. 2モーションの比較

- モーションA（基準）とB（任意）にアバター・モーションを個別に選択。
- 関節名の別名を対応付ける（例：RightArm ⇔ R_UpperArm、RightUpLeg ⇔ R_UpperLeg、Hips ⇔ Pelvis）。比較可能な対応部位数を記録。
- 同一骨格では元モデル単位の速度差、異なる骨格では身長比で正規化した速度差を表示。座標系・関節中心・可動域の厳密一致は未確認として警告。
- グラフではA実線、B点線。**元の時刻差を保持**と、0〜100％の局面正規化を選択可能。開始時刻差・最大速度差・ピーク時刻差は元の時刻基準で計算する。
- Bモデルは選択中の時刻に合わせて青緑色の半透明モデルで重ねて描画できる。
- 比較対象の関節対応が不足（3未満）の場合、数値比較・差異マーカーを無効にする。

## 5. 比較差異リングと個眼強調

- 既存の赤い運動検出マーカーは維持。
- 比較リングは別のレイヤーで「遅」（B開始遅延）、 「小」（速度／範囲小）、「大」（速度／範囲大）、「≈」（許容内）を色・文字の両方で表現。
- 表示数を1／3／5関節から指定。時間に合わせて関節の比較判定を更新し、選択した関節の個眼を点線で強調。
- 比較Bがない場合は差異リングを出さず、従来の運動マーカーのみ表示。VR中は詳しいグラフを表示しない。

**注意:** 「小」「大」「遅」は設定された相対閾値で検出された差。技能の良否や改善の要否を意味しない。

## 6. データ出力

CSV（UTF-8 BOM、CRLF）：
- `raw-synthetic-series.csv`：元アニメーション時刻、モデル相対関節位置、ローカル回転クォータニオン
- `derived-features.csv`：各関節・各サンプルの速度／角速度／加速度／角加速度／ジャークと運動開始・ピーク時刻
- `comparison-differences.csv`：対応関節の運動開始差・ピーク時刻差・最大速度差・マーカー種別（比較Bが有効な場合）

JSONは元の均等サンプリング系列と解析結果・計算条件を**別々のファイル**として保存する。Gitコミット、解析方式、座標単位、モーション素材の出典・ライセンス記載状況、比較モード、サンプル間隔・平滑化・閾値を記録。

人体実測、被験者の回答、正解モーション、技能の良し悪し、神経・筋信号、因果推定は扱わない。再現性は**独立した複数試行がない限り評価不可**と明記する。

## 7. 検証

- Windows Edge／WebGL2で複数アバターの3・4眼脚部表示を確認。
- 4眼の水平位置0.00〜0.49、中央への重なりと左右対称拡大を確認。
- グラフのシーク時刻と3Dのアニメーション時刻一致を確認。
- X BotパンチとAEGIS全身連動パンチについて13関節のマッピング、重ねグラフ・比較リング・個眼のハイライトを確認。
- 出力CSV（元時系列22列／導出特徴23列／比較差分17列）の列数一致を確認。
- 実機HMD／GameSir・Safariでの最終視認性と性能は未検証。
