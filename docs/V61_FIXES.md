# v61 — パンチの連結・X Bot Cの移植・左右交互パンチ

基準版：`11ed59c`（v60公開後の利用者による配色・バイザー設定更新を含む）。変更前を `backup-v60-before-v61-20261112` タグに保存。`public-appearance.json` の内容とrevisionを変更せず引き継ぐ。

## 依頼の反映

| 対象 | 変更 |
|---|---|
| X Bot パンチD | パンチA → パンチC の順に連続再生。A/Cそれぞれの本体姿勢・指のトラックを利用し、間とループ末尾に0.12秒の姿勢補間を挿入。A/B/Cの単体動作は変更しない。 |
| AEGIS NAVY / SOLDIER パンチB | X BotパンチCの実トラック `Boxer_Punching2` をAEGISの骨格へ適合。元のタイミング、腕・前腕・大腿の向き、腰・胸の回転を使用し、AEGIS固有の骨長を維持。 |
| AEGIS NAVY / SOLDIER パンチC | パンチAを右→左と交互に再生。左側は腕だけでなく、腰・胸・脚を含むAの左右反転。切替部に0.12秒の補間。 |
| AEGISの一覧 | 構え・肘曲げ・腕上げ・腕伸ばし・踏み込みを削除。静止・呼吸、歩行、走行、パンチA/B/Cの6動作に統一。 |

「パンチC」の新規追加はAEGIS2モデルが対象。X Botの既存パンチCは変更していない。通常ビューアー、設定メニュー、VRの動作選択、比較用セレクターは共通の候補リストを使う。削除したIDを以前の設定等から指定した場合は静止・呼吸へ戻す。元GLB内の旧クリップは素材履歴として残すが、利用者の選択肢には出さない。

## 時間・左右の扱い

X Bot Dの原アニメーション時間は約2.323333秒（A 1.10秒＋C 約0.983333秒＋補間2回）。AEGIS Bは元Cと同じ約0.983333秒。AEGIS Cは3.54秒（右A 1.65秒＋左A 1.65秒＋補間2回）。再生速度設定によって実際の再生時間は変わる。

X BotとAEGISでは同名の左右ボーンのX軸符号が異なるため、Bの移植ではX方向を反転して同名の左右へ対応付ける。肘・手首の位置を直接コピーして骨を伸ばすのではなく、上腕・前腕の向きをAEGISの骨長で再構成する。グローブの元形状は手首からオフセットされているため、手首は元の取付関係を保ち、ソースの前腕軸まわりの回内・回外を使用する。独立した指のボーンを持たないため、指の握り込みはX Botと同一ではない。

再生、原時刻シーク、動作フレームスライダー、解析、CSVの時間範囲を共通の動作長へ接続した。X Bot Dの内部IDは既存設定との互換のため `xbot_hook` を維持するが、旧Hookは再生せず新しい連結経路を使用。Dにもパンチ再生倍率を適用する。手動フレームスライダーも再生倍率を考慮して指定の原時刻へ移動する。

## 保持したもの

最新の公開配色とバイザーサイズ・角度、1本アンテナ・カメラ・メーター、肩装甲なし、初期1個眼、魚眼既定、1〜6個眼・単眼／双眼、CSV86列を維持。AEGIS13関節、X Bot32関節の骨格構造は変更しない。新しい動作は当然その動作に応じた速度・スコアを持つが、装飾の動きを運動量に混ぜる処理は追加しない。

新しい動作の付帯JSONに `motion_composition` と新しい `motion_revision_id` を記録する。既存のパンチA・歩行・走行等は従来の識別子と数値を維持。Bはソース動作を変更したので旧BのCSVとの同一視を避ける。

## 検証

- 単体：時系列4区間、周期、補間、左右反転の往復、元データ不変、トラック補間、不正入力を追加。従来の運動学・モデル・バイザー調整テストも実施。
- 新パンチ：Dの各非補間区間が元A/Cと一致すること、補間・ループ端で姿勢が飛ばないこと、Bの上腕・前腕・大腿の単位方向が元Cと一致すること、Cの左側がAの全身反転であることを検査。
- 各新動作の原時刻・再生倍率・スライダー・CSV長・改訂IDを確認。
- 変更対象外13動作（X Bot A/B/C/歩行/走行と両AEGISの呼吸/A/歩行/走行）の従来数値列がv60と一致。
- メニュー、ボーン長、配色・バイザー保存、1〜6個眼×単眼／双眼、縦画面、描画エラーを確認。各パンチ8局面、左右伸展、モバイル画面を保存。

検査環境はWindows Edgeの実WebGL2。実機iPhone/Safari、HMD、GameSirは未検証。AEGISはX Botと異なる13関節のモデルであり、足首・つま先・指を完全再現するものではない。足裏の物理接地、人体・装甲の衝突、技能の正しさを保証するものではない。
