# 人工複眼VR｜研究用プロトタイプ

公開サイト：<https://andre20290810.github.io/compound-eye-vr/>

本リポジトリはWebGL2で3Dアバターの複数部位を観察するための試作アプリです。X Bot・AEGIS NAVY・AEGIS SOLDIERのモデルを表示し、人工複眼の2〜6眼構成、局所カメラ、VR双眼／単眼、GameSir操作、運動スコアに連動した表示倍率の調整を行えます。

## v44：等倍・放射状の個眼レイアウトと回し蹴りFBX

- 2眼全身像の投影行列を、3〜6眼の各身体部位にも共有。個眼の骨盤・腰・腕・脚が上下視点移動および動作時の元の骨格位置に追従するように変更
- **放射距離0、全パーツ共通倍率1.00×** で、各身体部位を中央全身と同じ見かけの大きさ・元の位置に重ねる
- 放射状の広がり距離（共通）・全パーツの一括倍率を、個眼数選択付近の簡易スライダーから変更。値はローカルに保存
- 楕円の横幅・高さの細かい設定は、個眼レイアウト調整の一番下のチェックボックスをONにした場合だけ表示
- ユーザー提供の Roundhouse Kick.fbx から回転キーフレームを抽出した**回し蹴り**モーションをX Bot・AEGIS NAVY・AEGIS SOLDIERへ登録。AEGIS向けの骨格差分リターゲットは実験的な実装
- 計測画面は表示用運動スコアのグラフと上位6棒グラフを廃止し、**関節移動速度の時系列・角速度・主要部位の最大速度発生時刻の順序**を表示。グラフ数値をCSV出力可能

[設計・数値の意味・モーション出典と制限](docs/radial-motion-v44.md)

研究上の限界：新たな人体実測情報を追加する方式ではありません。動作認識率・回答時間・主観的負担などで有用性を比較実験する前に、技術が技能評価に役立つと断定しないでください。

## v43：単眼／双眼モードの整理と動作数値のグラフ化

- 通常起動は **2個眼・通常立体視・角度一致** を1枚のビューア（単眼）に表示。
- **3D閲覧** と **VRゲーム** は単眼のビューアモードを切替。ビューア右上の **双眼表示** を選択するとHMD用の2画面へ移り、VR終了で単眼へ戻る。
- 旧「VR左右半身の中央寄せ」パネルと長い説明文は表示しない。既存の保存値・コントローラー操作は保持。
- 実験計測を個眼レイアウト調整の下へ移し、動作選択の重複を解消。グラフ・数値・説明を主要機能に変更。
- モーションの関節速度／角速度／表示用運動スコアの時系列、関節ごとの最大運動スコアを可視化。ピーク関節・値・時刻と結果の限界を文章化する。
- **グラフ数値CSV** は全関節の解析値・最大値を含むUTF-8 CSV（16列）。
- 旧のCSV／JSON生ログ機能は「詳細ログ」に残す。

[計算方法・単位・解釈上の注意](docs/motion-graphs-v43.md)

注意：ここで可視化するのは内蔵3Dアニメーション由来の計算値です。実測人体運動ではなく、人間の運動認識における人工複眼の効果を示すものでもありません。

## v42：通常／VR独立レイアウトとコンパクト配置調整

通常画面の**「調整画面」**ボタンで、ビューア・アバター／動作／個眼数・部位別スライダーだけを表示する専用画面に切り替えます。VR双眼プレビューは左右2画面の描画パスを使い、通常ビューは旧設定を維持します。個眼は位置（上下／左右）、横幅、高さを調整でき、詳細の画角・カメラ距離・映像内の上下位置は展開すると表示されます。水色の丸いハンドルのドラッグでも位置を変えられます。

- 通常ビューの公開値: `public-lens-defaults.json`（以前のv36・v41の値を維持）
- VR専用の公開値: `public-vr-lens-defaults.json`（VR固有のレンズ領域・カメラ設定）
- VR専用のローカル保存: `compoundeye.v42.vrLensOverrides`
- 左右共通中央寄せ: `compoundeye.v41.vrAlignmentByAvatarAndCount`（15組のまま）
- VR用の「保存」は現在のアバター×眼数の値だけを保存し、通常ビューを上書きしません。
- 「VR設定JSON出力」で生成したファイルは、GitHubの同名ファイルへ反映することで公開初期値にできます。

**制限：** 実機の画角・ゴーグルレンズ・装着位置まではプレビューできません。詳しくは [v42 VR配置校正ガイド](docs/vr-calibration-v42.md) を参照してください。

研究利用の有用性は未検証です。3Dモデル由来の人工複眼にすることで運動認識が改善するかどうかは、従来の単一視点・固定複眼・適応型複眼などと区別して評価する必要があります。

## v41の追加機能

- **VR位置調整：** LTで左右を対称的に中央へ、RTで対称的に外側へ。左右交差防止、倍率・画角は不変
- **設定保存：** X Bot／AEGIS NAVY／AEGIS SOLDIER × 2〜6眼の15組を別管理。Y長押し900msで現在の組のみ保存。旧v39設定を退避・平均値で対称設定に移行
- **眼数切替：** X長押し900msで10秒ごとに2→3→4→5→6→2を切替
- **実験計測：** 折りたたみ式「実験計測」から開始・停止・消去、骨格CSV・個眼CSV・表示／イベントCSV・実験条件JSONをダウンロード。約30Hzを目標に記録
- **比較条件：** A＝固定5眼・関節マーカー、B＝運動スコア連動の個眼選択・面積拡大・関節マーカー。アバター・モーション・再生速度・眼位置を揃え、0秒から繰り返し再生

**重要：** 本データは3Dアニメーション由来の計算値であり、人体の実測値、実測精度、技能の正誤判定ではありません。取得できる運動スコアは表示制御用で、認知機構や身体技能の因果推定には使用できません。

出力CSVの列・単位、匿名試行ID、素材メタデータと制限については [実験データ仕様 v1](docs/experiment-data-schema-v1.md) を参照してください。

## 使い方

1. `index.html` を開く（推奨：公開サイトのHTTPS経由）。
2. 観察するアバター・動作・個眼数を選択。
3. 必要に応じて「🥽 3D閲覧」「🎮 VRゲーム」を開始。VR時はジャイロOFF、GameSirのLBでメニュー、Aで決定、Bで戻る、RBで双眼／単眼を切替。
4. VRの左右位置はLT／RTで調整し、Y長押しで保存。保存値はブラウザのローカル領域に残り、アバター・個眼数ごとに復元される。
5. 通常画面の「実験計測」を展開。条件選択・再生・計測開始・停止・CSV／JSON出力を行う。

個眼レイアウト調整は初期状態で折りたたまれています。研究用ログの詳細グラフも通常画面には常時表示しません。

## フォルダ

- `index.html`: 3Dモデル、描画、入力、実験計測パネル
- `public-lens-defaults.json`: 公開用の個眼配置初期値
- `build-manifest.json`: ソース実装GitコミットID（実験環境JSONに反映）
- `docs/experiment-data-schema-v1.md`: データ仕様・単位・制約

## 開発・公開

GitHub Pages は `main` ブランチのルートを配信します。HTML／JSONを編集・コミットして公開できます。ブラウザ環境によってはGamepad API、Wake Lock、VR画面向きなどの対応状況が異なります。GameSir実機およびスマートフォン上のすべての組合せでの動作は保証していません。
